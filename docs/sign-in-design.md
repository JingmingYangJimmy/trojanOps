# Sign-in reference

The user-requested screenshot governs the demo sign-in at `/`, including the USC primary monogram. This explicit request overrides the mark restriction for this page. Keep the existing demo authentication and project disclaimer.

At desktop size the reference uses a centered 530px notice, a 245 × 80px monogram, and a 372px form. Use Source Sans 3, Cardinal, white panels, a muted page background, 20px labels, 16px body copy, 40px inputs and a 50px button. The notice has a blue left edge and the form a Cardinal top edge. Both have subtle elevation. Small screens retain the order with 20px side gutters and wrapping recovery links. Password visibility, focus states, submit errors and pending feedback remain functional.

Logo source is https://identity.usc.edu/identity/logos-marks/ and the public PrimaryMonogram.png asset.
